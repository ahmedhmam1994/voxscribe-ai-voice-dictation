Why Windows warns about the VoxScribe installer

The short version: VoxScribe is a free app without a paid code-signing certificate, so Windows has never seen the file before and asks you to confirm. Here is what to click, how to skip the warning completely, how to check the file yourself first, and exactly what the installer changes on your PC.

What you will see, and what to click

When you open VoxScribe-Setup.exe, a blue box may say "Windows protected your PC" with only a "Don't run" button.

  1. Click More info under the message.
  2. Check that the app name says VoxScribe-Setup.exe and the publisher says Unknown publisher.
  3. Click Run anyway.

You only see this once. Updates you install later may show it again, because each new version is a new file to Windows.

Why it happens

Windows SmartScreen trusts a program in one of two ways: it is signed with a certificate that costs hundreds of dollars a year, or enough people have already downloaded that exact file. VoxScribe is free, open source and made by one person, so it has neither yet. The warning says "we don't know this file", not "this file is harmful".

Some antivirus tools are also wary of apps that listen to the keyboard. VoxScribe has to: it watches for your hotkey (F9 by default) and types your words into the window you are using. It does not record what you type, and the code that does this is public.

Skip the warning: install with a package manager

The warning is attached to files downloaded through a web browser, so installing from a package manager usually avoids it. Open PowerShell or Terminal and run one of these.

winget (built into Windows 10 and 11):

winget install ahmedhmam1994.VoxScribe

Scoop:

scoop bucket add voxscribe https://github.com/ahmedhmam1994/scoop-voxscribe
scoop install voxscribe

Both check the installer's fingerprint (its SHA-256 hash) before running it, so you get the same file as from the website.

Check the file yourself before running it

  • Compare the fingerprint. Every release lists the installer's SHA-256 hash at the bottom of its notes on the releases page. In PowerShell, in the folder you downloaded to, run the command below and check that the two match exactly.
Get-FileHash .\VoxScribe-Setup.exe -Algorithm SHA256
  • Scan it with many engines at once. Upload the file to VirusTotal, which runs it past about 70 antivirus scanners. One or two vague hits on a new unsigned app are common; a crowd of named detections is not, and should be reported.
  • Read the code. Both apps are MIT licensed, and the full source is on GitHub. You can build the app yourself from it.

Exactly what the installer changes

WhatWhere
The app%LOCALAPPDATA%\Programs\VoxScribe, for your user only
ShortcutsStart menu, plus a desktop shortcut only if you tick the box
Your settings and word listsYour user registry key, HKEY_CURRENT_USER\Software\VoxScribe
The speech modelDownloaded on first launch to %USERPROFILE%\.cache\huggingface\hub
Admin rightsNot needed
Services, drivers, startup entriesNone

To remove it: Windows Settings, Apps, VoxScribe, Uninstall. That removes the app and its shortcuts. Your settings and the speech model stay, in case you reinstall; delete the registry key and the model folder above to remove those too.

Questions

Will you sign the app?

Yes. A free signing program for open source projects was not an option, so a paid code-signing certificate is planned and will be bought as soon as Pro sales cover it. Even then, Windows only stops warning after the signed app has built some download reputation. Until then this page, the published hashes and the open source code are the way to check it.

My antivirus deleted the installer, or removed VoxScribe after installing. What now?

If Defender names it Trojan:Win32/Bearfoos.A!ml, the !ml means a machine-learning guess, not a match with known malware. This is a false alarm. VoxScribe is open source, it is not signed yet, and it uses a global hotkey and types into other windows, which is a pattern antivirus programs often flag in unsigned apps. Check the hash first (see above). If it matches, you can put it back:

  1. Open Windows Security, then Virus & threat protection, then Protection history.
  2. Find the VoxScribe item, open Actions, and choose Restore, or Allow on device.
  3. If it keeps coming back, add the folder %LocalAppData%\Programs\VoxScribe as an exclusion under Manage settings, then Exclusions, and run the installer again.

Your settings and Pro license are stored separately and are kept. You can also install with winget instead. Please open a GitHub issue with the antivirus name and the exact detection name it shows, so the false alarm can be reported to the vendor.

Does the Android app have the same problem?

A little. Android asks you to allow installs from your browser or file manager the first time you open the APK, because it is not from the Play Store. See the Android guide for the steps.
