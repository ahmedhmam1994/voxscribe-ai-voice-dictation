How to make subtitles from a video or audio file

  1. Install VoxScribe and let it download the speech model on first launch (internet needed once)
  2. Tick Also save .srt captions when importing a file under the Import Audio button
  3. Click Import Audio and pick your file, or pick several
  4. Wait for it to finish. The transcript appears in the app, and an .srt file with the same name is saved right next to your original file

Open the .srt in any video editor or player, such as VLC, DaVinci Resolve, Premiere Pro or CapCut, or upload it as a caption track on YouTube.

Why use a local tool for subtitles

  • Private. Interviews, meetings and client footage never leave your computer.
  • No limits or bills. No upload caps, no minute counters, no subscription. The app is free and open source.
  • Batch friendly. Select a whole folder's worth of files and let it run through them.
  • Many formats. wav, mp3, m4a, mp4, mov, flac, ogg, wma, aac and webm.
  • Many languages. About 28 languages, or auto-detect. Turn on Translate to English to get English subtitles from other languages.
Be realistic about the result: accuracy depends on audio quality and the model size, and each subtitle line covers one spoken segment rather than single words. It is a strong first draft for captions, but skim the file before publishing, especially for names and technical terms. You can add those to the custom vocabulary or word replacement lists in Settings to fix repeat mistakes.

Frequently asked questions

Is my video or audio uploaded anywhere?

No. VoxScribe transcribes the file on your own PC with the Whisper model, so the audio never leaves your machine. The only internet use is a one-time download of the speech model on first launch.

Which file types can I turn into subtitles?

Common audio and video formats work, including wav, mp3, m4a, mp4, mov, flac, ogg, wma, aac and webm. Anything the bundled ffmpeg-based decoder understands should load.

Can I generate subtitles for several files at once?

Yes. Select multiple files in the import dialog and VoxScribe works through them one after another. With the .srt checkbox ticked, it saves a matching .srt next to each source file.

Can it translate subtitles to English?

Yes. Turn on Translate to English in Settings and speech in other languages comes out as English text. It only translates into English.

How accurate are the timestamps?

Timestamps come from Whisper's own speech segments, so each subtitle line covers one spoken segment rather than single words. That works well for captions, but you may want to review long lines before publishing.
