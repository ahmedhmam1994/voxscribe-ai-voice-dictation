Talk Your AI Prompts Instead of Typing Them

Why speak a prompt

Most people talk several times faster than they type, and they explain more when they talk. That extra context is exactly what makes an AI answer better: the constraint you would have skipped, the error message you would have summarised, the "and keep it short" at the end. Speaking also keeps your train of thought going while you think out loud.

How it works

  • Click into the prompt box, in a browser tab, a desktop app, a code editor or a terminal.
  • Hold F9 and say what you want. Let go.
  • A moment later the text is typed into the box, as if you had typed it. Read it over, then send it as usual.

VoxScribe types the words instead of pasting them, so whatever you copied earlier (a stack trace, a snippet of code) is still on your clipboard to paste into the same prompt.

Tips for better prompts by voice

  • Teach it your words. Add project names, libraries and people to the custom vocabulary, so "Supabase" and "PySide" come out right the first time.
  • Fix the ones it keeps missing. A word replacement such as pie test => pytest corrects the same mistake every time, everywhere.
  • Structure as you go. Say "new line" or "new paragraph" between parts of a prompt, and "scratch that" to take back the last thing you said.
  • Dictate code names too (Pro). Code dictation turns "camel case user name" into userName and "open paren x close paren" into (x).

What stays private

Your voice is turned into text on your PC and never uploaded. The prompt itself goes wherever you send it, so the AI service you use sees your words as it always would; VoxScribe adds nothing to that. The privacy at a glance page lists every connection VoxScribe makes.

Frequently asked questions

Can I dictate prompts to ChatGPT or Claude by voice?

Yes. VoxScribe types into any Windows app that accepts typed text, so it works in the ChatGPT and Claude websites and desktop apps, in coding assistants inside editors, and in terminals. Hold F9, talk, let go, and the prompt is typed where your cursor is.

Does my voice go to the AI company?

No. VoxScribe transcribes on your own computer with a local Whisper model, and only the finished text is typed into the prompt box. What you then send is up to you.

Is it free?

Yes. Dictation, custom vocabulary, word replacements and voice commands are free with no word limit. An optional one-time Pro key adds extras such as code dictation and the larger, more accurate models.

Does it work with coding tools?

It types into editors and terminals like any other app. For identifiers and symbols, the Pro code dictation mode writes them the way code needs.
